## Implementation Scope & Seam Contract

1. **Rest-Chord Prevention**: Refine `generate_musicxml_from_omr` to ensure that rest candidates are never marked or written with the `<chord/>` tag, as chords must only contain pitches.
2. **Timing Overlap Resolution**: In `timeline.py` and `musicxml_generator.py`, detect and resolve overlapping events assigned to the same voice. If two events overlap on the same voice, either shift them, assign them to distinct voices (e.g. if stem directions or vertical positions indicate polyphony), or drop the redundant/unevidenced overlapping event.
3. **Dynamic Measure Capacity**: Support extracting or inferring time signatures (e.g. 12/8 for Lesson-5) rather than hardcoding a 4/4 meter, ensuring padding rests are calculated correctly.
4. **End-to-End Test Verification**: Add unit tests verifying that the OMR pipeline successfully handles overlapping notes/rests without crashing, and that generated MXL/MusicXML files pass `ScoreIR` Pydantic validation.
